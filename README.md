# 光合作用互動實驗室 (Photosynthesis Interactive Lab)

一個高視覺質感、互動式的植物生理與光合作用生化機制教學模擬系統。

## 🌟 核心互動特色與功能

1. **大氣二氧化碳 (CO₂) 捕獲與氣孔機制**
   - 點擊「吸入 CO₂ 氣體」或直接點選畫布上方大氣，二氧化碳分子自環境中漂移並透過下表皮氣孔 (Stomata) 擴散進入葉肉細胞。
   - 微觀視角支援調整「氣孔開度 (Stomata Aperture)」，觀察保衛細胞膨脹與氣體擴散通量關係。

2. **水分吸收與木質部向上輸導 (H₂O)**
   - 點擊「根部吸收水份」或點選土壤層，水分子經由根毛滲透吸收，依靠蒸散拉力與木質部 (Xylem) 導管逆地心引力上升輸送至葉肉組織。

3. **葉綠體光反應與卡爾文循環 (合成葡萄糖與釋氧)**
   - 當收集到 6 個 CO₂ 與 6 個 H₂O，在足夠光照條件下啟動光合作用：
     - **類囊體光反應**：光裂解水分子產生電子、質子與 **氧氣 (O₂)**，氧氣以微氣泡形式從氣孔向大氣釋放。
     - **基質卡爾文循環**：利用 ATP/NADPH 固定 CO₂，還原合成 **六碳葡萄糖 (C₆H₁₂O₆)**。

4. **葡萄糖去向抉擇系統 (Glucose Fate Choices)**
   - 每次成功合成葡萄糖，系統會即時彈出代謝抉擇視窗，由使用者親自指派轉化途徑：
     - **途徑一：運送至根部儲存為「澱粉 (Starch)」**
       - 轉化為蔗糖經由韌皮部篩管 (Phloem) 向下主動運輸至根部。
       - 脫水縮合為螺旋狀 α-1,4 糖苷鍵澱粉顆粒，根部逐漸長出膨大儲藏塊根！
     - **途徑二：構建「纖維素細胞壁 (Cellulose Cell Wall)」**
       - 經由細胞膜纖維素合成酶複合體 (CESA) 聚合為直鏈 β-1,4 糖苷鍵微纖維。
       - 平行鏈間以密集氫鍵交聯，強化葉片邊緣與莖幹次生加粗，提升植物生命活力！

5. **分子檢驗小實驗：碘液檢驗澱粉**
   - 具備右側試管實驗區，點擊「💧 滴加碘液檢驗澱粉」。
   - 當根部儲有澱粉時，碘液試管會從黃褐色立即變色為**深藍黑色 (陽性反應)**，並附有分子構型原理解析！

6. **三大動態視角無縫切換**
   - 🌿 **全株輸導視角**：觀察太陽、大氣、葉片、莖部雙向維管束 (木質部水上行/韌皮部糖下行) 與地下根系。
   - 🔬 **氣孔與葉綠體微觀剖面視角**：剖析柵狀/海綿組織、保衛細胞開閉、類囊體膜光反應堆與基質卡爾文循環。
   - 🧬 **葡萄糖去向探索視角**：直觀比對 α-螺旋澱粉鏈與 β-剛性平展纖維素微纖維分子模型。

7. **聲學與觸覺回饋**
   - 內建 Web Audio API 音效合成引擎（水滴、氣體微泡、合成成功和弦、澱粉鎖定音），支援一鍵靜音。

## 🚀 啟動與使用方式

本專案為純前端原生架構（HTML5 + Vanilla CSS + JavaScript Canvas & Web Audio），無需安裝大型相依套件：

### 方式一：直接以瀏覽器開啟
直接在檔案總管中雙擊打開 `index.html` 即可完整運行。

### 方式二：透過本地 HTTP 伺服器開啟
在終端機中執行：
```bash
# Python
python -m http.server 8080

# 或 Node.js
npx serve -l 8080
```
接著在瀏覽器造訪：`http://localhost:8080/`
